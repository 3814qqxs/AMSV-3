## V2 Planning Notes

> Carry forward specific, actionable findings from above. Each item becomes a candidate for the next `/brainstorm` or `/plan` session.

### Must Fix (regressions / broken experience)

- [ ] **1-A** Background scroll still fires per word, not per verse (3.2)
- [ ] **1-B** NavSheet drag-to-dismiss has no spring animation on close (6.2, 12.2)
- [ ] **1-C** Drag pill non-functional in chapter picker view (6.3)
- [ ] **1-D** HistoryPane → Change → NavSheet fails to recess on second navigation (7.9)
- [ ] **1-E** Animation jank / jitter during playback state transitions (12.1)
- [ ] **1-F** Psalms (and potentially other long books) fails to load — investigate payload/row limit (12.5)

### Should Have (meaningful UX gaps)

- [ ] **2-A** Tap anywhere on reading pane to play / pause (1.3, 4.6)
- [ ] **2-B** HistoryPane: replace "Close" button with swipe-up pill gesture (7.6)
- [ ] **2-C** HistoryPane: replace "Change" button with swipe-up to NavSheet — *design Q required first* (7.9)
- [ ] **2-D** NavSheet: default testament matches currently active scripture (6.5)
- [ ] **2-E** Cross-reference / commentary: touch gesture triggers, not keyboard-only (10.1, 10.2)
- [ ] **3-A** Replace "ASV" label with "AMSV" throughout (1.4, 8.1)
- [ ] **3-B** Unify chrome recession — TopBar and verse badge stay visible like WPM (5.1, 5.2)
- [ ] **3-C** Replace "end of chapter" text with prev / next chapter arrows (2.7)
- [ ] **3-D** Pin `← Books` button above the chapter scroll area (6.16)

### Nice to Have (polish / delight)

- [ ] **4-A** Phrase-based word reveal — musical phrasing cadence (2.1) — *brainstorm required*
- [ ] **4-B** Three-line foreground stage with gradient transition into background (2.8)
- [ ] **4-C** Cinematic cross-reference transition — travel through text to target (10.1 finding) — *brainstorm required*
- [ ] **4-D** Speed preset labels (Low / Med / High) as alternative or complement to WPM number (4.7)
- [ ] **4-E** Welcome splash or login-based default chapter (1.2) — *brainstorm required*

### Architecture / Infrastructure Flags

- Any feature requiring user identity (reading history, bookmarks, shared annotations) needs a `users` table — flag before designing any sign-in feature.
- Commentary + cross-reference data entry pipeline (via GitHub) — separate activity, not blocking V2 feature work.
- Verify all 66 books load correctly before Sprint 2 — systematic endpoint test.
